# Writing style

- Language: English for all docs, AC, TC, bugs and Jira text.
- Tables and bullets. No long prose paragraphs.
- Short sentences, max 20 words each.
- One behavior per AC. One action per test step.
- Observable wording only. Avoid "works correctly", "succeeds", "as expected".
- No "written by AI" note or disclaimer.
- Do not invent rules the source does not state. List them as open questions.
